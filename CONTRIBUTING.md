# Contributing to MirrorOS

Thanks for your interest in contributing to MirrorOS.

## Development Workflow

1. Fork the repository and create a feature branch from `dev`.
2. Keep changes scoped and focused.
3. Add tests and documentation updates where applicable.
4. Open a pull request into `dev` with a clear summary.

## Commit Guidelines

- Use clear, imperative commit messages.
- Prefer conventional commits where possible.

## Code Quality

- Keep code readable and modular.
- Avoid introducing unrelated refactors in feature PRs.
- Respect local-first and privacy-by-default design goals.

## Reporting Issues

- Include steps to reproduce.
- Include expected and actual behavior.
- Include environment details.
