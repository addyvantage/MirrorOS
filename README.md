# MirrorOS

MirrorOS is a local-first personal context platform for building a private, searchable memory layer.

## Features

- Personal Context OS
- Taste Graph
- Voice Emulation
- Receipts

## Principles

- Local-first by default

## Planned Connectors

- YouTube
- X (Twitter)
- Email
- Calendar
- Notes

## Roadmap

- v1: YouTube + Twitter Voice Reply

## Push Policy

Push policy: Only milestone-level stable checkpoints are pushed to main.
